# jonahs.site

Source for [jonahs.site](https://jonahs.site), the personal site of Jonah Waltz-Rieber.

Plain HTML, CSS and JavaScript with no build step, hosted on GitHub Pages.

- `index.html`: home page. The hero background is a simulated solar radio spectrogram drawn on a canvas.
- `resume.html`: printable one-page résumé (`Jonah_Waltz-Rieber_Resume.pdf` is generated from it).
- `card.html`: full-screen QR code for jonahs.site, for sharing in person.
